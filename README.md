# BiliLite 2 · iPhone 4S / iOS 8

面向越狱 iPhone 4S 的原生轻量 B 站客户端，采用 ARMv7、iOS 8.0 最低系统版本和 rootful DEB 安装方式。

## 当前版本：0.9.1

- 推荐、热门、搜索、收藏、历史、二维码登录和直播
- 视频点击即播；竖屏播放，手动点击全屏进入横屏
- 直播点击即播；竖屏显示房间信息、收藏和画质，点击全屏才进入横屏
- 原生 AVPlayer，自绘纯色线性图标；长按 2× 提示短暂出现在右上角
- 全屏左侧上下滑动调亮度，右侧上下滑动调播放器音量
- 自动画质：根据吞吐量、缓冲和卡顿选择兼容的 360P / 480P / 720P，也可手动固定
- 直播优先兼容 HLS + AVC 流，根据网络情况回退到流畅
- 保留播放进度，优化暂停后的全屏返回行为
- 使用 ImageIO 限制缩略图解码尺寸，缓存重复绘制的线性图标，减少内存和 CPU 消耗
- Keychain 保存账户会话，不在日志或偏好设置中保存 Cookie

## 安装

可通过 GitHub Actions 的最新成功构建下载对应 DEB，或使用仓库里的 [0.9.1 直接下载](downloads/BiliLite-iOS8-v0.9.1.deb)（发布工作流完成后更新）。用 iFile 安装 DEB，建议覆盖前先退出应用。

## 验证说明

GitHub Actions 执行源代码回归检查、ARMv7 原生编译、签名与安装包结构验证。实际网络、视频画质切换、登录和旋转效果仍需在实体 iPhone 4S 测试。

部分 DASH 分离音视频、DRM、HEVC、付费或受平台限制的源无法由 iOS 8 原生解码器播放，代码不能保证所有视频和直播源兼容。
