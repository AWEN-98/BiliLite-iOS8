# Bili Lite for iPhone 4s

An experimental native iOS 8.4.1 / armv7 jailbreak app. The app resolves public BV videos, shows their metadata and attempts to play compatible MP4 streams with the iOS media player.

The `.deb` is built by GitHub Actions. See Actions for artifacts. **Playback depends on Bilibili API and codec compatibility; a successful build does not guarantee online video playback.**

Minimum iOS 8.0; intended for rootful jailbreak devices. Personal project, unaffiliated with Bilibili.
